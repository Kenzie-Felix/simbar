                           QUICK SUMMARY
================================================================================

PROBLEM:
  The "Add Item" button on Staff → Request Loan page was non-functional.
  Items were not being added to the "Items to Borrow" list.

ROOT CAUSE:
  Template cloning using string manipulation (innerHTML.replace) was unreliable
  and caused DOM element creation to fail.

SOLUTION:
  Replaced string-based template manipulation with robust DOM-based approach
  using querySelectorAll and direct element attribute updates.
